# Projetos Flutter

Repositório com exemplos simples desenvolvidos em Flutter utilizando a linguagem Dart.

## Objetivo

Registrar minha prática com desenvolvimento mobile, explorando conceitos básicos do Flutter, criação de interfaces, organização de widgets e fundamentos da linguagem Dart.

## Tecnologias utilizadas

- Flutter
- Dart

## Conteúdos praticados

- Estrutura básica de aplicações Flutter
- Criação e organização de widgets
- Componentes visuais
- Layouts simples
- Navegação entre telas, quando aplicável
- Manipulação básica de estado, quando aplicável

## Observação

Os projetos deste repositório têm finalidade educacional e fazem parte do meu processo de aprendizagem em desenvolvimento mobile.
